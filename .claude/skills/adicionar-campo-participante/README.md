# Skill: adicionar-campo-participante

Skill do Claude Code que adiciona (ou altera) um campo no cadastro de participantes, propagando a mudança por `index.html`, `script.js` e `style.css` no padrão do projeto. Ela usa só ferramentas de leitura e edição (`Read`, `Grep`, `Glob`, `Edit`).

**Como reutilizar em outro projeto:** copie esta pasta inteira para `.claude/skills/` do seu projeto e reinicie o Claude Code. Depois peça algo como "adicione o campo telefone ao cadastro" ou chame `/adicionar-campo-participante`. Ajuste os `id`s e nomes de função no `SKILL.md` se o seu projeto usar outros.
